# Base de Données

MongoDB est utilisé via Mongoose.

Modèle initial implémenté:

- `User`: identité, téléphone indexé, rôle, statut, vérification téléphone, refresh token hash et OTP simulé.

Les prochains modèles seront `Address`, `DriverProfile`, `Vehicle`, `Delivery`, `Payment`, `Wallet` et `Rating`.
